# ⚡ 1-MINUTE QUICK START

## What You Need to Do

1. **Go to:** https://formspree.io/
2. **Sign up** with `recruitment.ubn@outlook.com`
3. **Create form** → Name it anything → Copy the **Form ID** (e.g., `abc123def`)
4. **Edit file:** `c:\Users\Administrator\Documents\websites\UBN RECRUITMENT\static_site\index.html`
5. **Find line 2032:**
   ```javascript
   formspreeEndpoint: 'https://formspree.io/f/xyzabjnl',
   ```
6. **Replace `xyzabjnl`** with your Form ID
7. **Save file** (Ctrl+S)
8. **Test:** Open website, submit any form, check inbox

**DONE! ✓ All forms will now email to recruitment.ubn@outlook.com**
